Public API

Headless systems, optional adapters.

Import every public type from src/index.js during development or from release/littleenvironment.min.js in a browser.

AreaExportsPurpose

Typical integration

import { CelestialClock, WeatherSystem } from './release/littleenvironment.min.js';

const clock = new CelestialClock({ dayDurationSeconds: 900 });
const weather = new WeatherSystem();

export function update(deltaSeconds, cameraBounds) {
  clock.update(deltaSeconds);
  return weather.update(deltaSeconds, cameraBounds).climate;
}
See the source JSDoc for parameter-level details and the interactive demos for complete browser examples.
